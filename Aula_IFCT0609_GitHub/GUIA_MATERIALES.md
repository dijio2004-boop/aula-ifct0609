# Añadir materiales al aula

1. Sube el PDF a la carpeta `materiales` del repositorio. Utiliza un nombre sin espacios.
2. Edita `resources.json` y añade un objeto con `name` (nombre del archivo) y `url` (`materiales/nombre.pdf`). Separa los objetos con comas.
3. Guarda el cambio. GitHub Pages actualizará el aula automáticamente cuando esté activado desde la rama main y la carpeta raíz.

El progreso se guarda en cada navegador. Al cambiar de dirección web, el progreso anterior no se traslada automáticamente.
